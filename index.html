XoXo Inventory App

Versi 3.5.0 (Offline PWA)

Aplikasi manajemen inventaris barang dan ruangan berbasis Progressive Web App (PWA). Berjalan mandiri tanpa database eksternal, dengan penyimpanan media foto di IndexedDB dan data di LocalStorage.

Unduh Aplikasi Android (.APK)

Versi installer offline untuk dipasang langsung di HP Android.

Framework: Native Vanilla JS, CSS3, HTML5

Penyimpanan: Client-side LocalStorage & IndexedDB

Scanner Engine: HTML5-QRCode Library

Credit: Dibuat oleh XoXo Team

Syarat & Ketentuan Penggunaan

1. Penyimpanan Data Lokal: Seluruh data disimpan sepenuhnya di browser perangkat. Aplikasi tidak mengirim data ke server mana pun.

2. Risiko Penghapusan Cache: Menghapus cache browser dapat menghilangkan data jika belum dicadangkan. Disarankan rutin mengunduh cadangan JSON.

3. Akses Kamera: Fitur pemindai QR Code memerlukan izin kamera secara lokal.

4. Pemasangan Berkas APK: Pengguna dapat memasang berkas XoXo.apk secara mandiri dengan mengizinkan instalasi dari sumber tidak dikenal di setelan Android.
